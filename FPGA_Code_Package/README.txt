======================================================
项目名称：基于Zynq异构平台的肤色自适应白平衡系统
======================================================

【目录结构说明】
1. src/       : 核心源代码目录
                - ov5640_capture.v (底层OV5640 DVP采集状态机)
                - pins.xdc (物理引脚约束文件)
                - visual_test.py (上位机Python图形界面与白平衡算法)
                - send_file.py (串口极限分包传输脚本)
2. board/     : 硬件与实测结果展示
                - design_1_wrapper.bit / .hwh (Vivado生成的硬件比特流与描述文件)          
3. skill/     : 基于AI大模型协作开发的技能包(包含提示词与踩坑记录)
4. 成功事例  : 相关界面与实物图

【项目复现说明】
1. 硬件连线：参照 pins.xdc 将 OV5640 接入 Pmod A/B。
2. 硬件端：在 Vivado 中打开工程，可直接烧录 board 目录下的 .bit 文件。
3. 上位机端：在 PC 端运行 `pip install opencv-python numpy matplotlib`，随后运行 `python  visual_test.py ` 即可启动图形界面。

【系统现状客观说明】
本项目采用“软硬协同验证”方案。底层已完成完整的 RTL 综合、时序收敛并生成 Bitstream；在无网络、无外部驱动的极端受限环境下，团队通过自行编写的 `send_file.py` 脚本，成功将硬件描述文件(.hwh)跨物理链路部署至板卡系统。
受限于底层评测环境的系统镜像驱动缺失，核心的白平衡算法全功能闭环与交互展示，最终在上位机完成验证。
